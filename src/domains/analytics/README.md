# Analytics Domain (`src/domains/analytics`)

## Purpose
Records and processes student preparation events, test performance tracking, and administrative dashboard metrics.

## Boundaries & Constraints
*   **Drill-Down Requirement**: Administrative charts and metrics must support drill-down capabilities, allowing click-through actions to view underlying source records.
*   **Performance Tracking**: Tracks topic-level weak areas and error rates to feed preparation analytics.
*   **Data Minimization**: Collects only events relevant to student learning outcomes and system operations.
